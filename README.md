# 🐧 carsonOS

A lightweight, Ubuntu-based Linux distribution built as a personal OS project.

## 🚀 About

**carsonOS** is an experimental Ubuntu-based operating system focused on being simple, lightweight, customizable, and fun to build.

The project is currently being developed around the latest Ubuntu base, with **XFCE** planned as the default desktop environment for a lightweight and VM-friendly experience.

## ✨ Goals

- 🐧 Build a customized Ubuntu-based Linux distribution
- 🖥️ Use XFCE for a lightweight desktop experience
- 📦 Provide a familiar `apt` package-management base
- ⚙️ Add carsonOS-specific tools and customization
- 🎨 Create custom branding, wallpapers, and system artwork
- 💿 Produce bootable ISO images
- 🤖 Automate ISO builds with GitHub Actions
- 🧪 Keep the project experimental and easy to modify

## 🔧 Building

The build system is still under development. Once the initial build scripts are ready, ISO images will be generated automatically through GitHub Actions.

## 📦 Package Management

carsonOS will use Ubuntu's `apt` ecosystem as its underlying package system. Custom carsonOS tooling may be added on top of it as development continues.

## 🧪 Project Status

> ⚠️ **Early development:** carsonOS is experimental and is not currently intended to replace an existing operating system.

Expect broken builds, missing features, and the occasional Linux moment™. 😭
